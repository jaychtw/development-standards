# Changelog

All notable changes to the Universal Game Development Standard (UGDS) are recorded here. Use semantic versions and pin a release tag or commit SHA in each game project.

## [AICP 1.1.0] - 2026-10-29

### Added
- Lightweight end-of-cycle retrospective as a default collaboration practice.
- Evidence-based lesson classification and promotion rules for AICP, UGDS, project records and technical references.
- Proportionate AI initiative and change-control limits to reduce owner coordination burden.

### Notes
- No automatic revision for every development cycle; no background activity promised.
- UGDS v1.0.0 and existing project acceptance criteria remain unchanged.

## [AICP 1.0.1] - 2026-10-29

### Clarified
- Explicitly identify https://github.com/jaychtw as the default discovery namespace for the owner's projects.
- Prioritize approved GDDs and design decision records when reconstructing intended product behavior.
- Require agents to verify access and disambiguate repositories rather than assuming universal visibility.

### Notes
- UGDS 1.0.0 and individual project acceptance criteria remain unchanged.

## [AICP 1.0.0] - 2026-10-29

### Added
- AI Collaboration & Continuity Protocol for context reconstruction, decision preservation, approval gates and agent handoffs.
- Project state and conversation-starter templates, plus a central README.

### Notes
- AICP is independently versioned; UGDS remains unchanged at 1.0.0.
- No retroactive adoption or game acceptance changes.

## [1.0.0] - 2026-10-23

### Added
- Universal baseline for bilingual English/Traditional Chinese games with live switching.
- Desktop and mobile interaction, responsive layouts, accessibility, and recovery expectations.
- Mandatory visual production standard distinguishing concept references, functional prototypes, and production-ready artwork.
- Gameplay integrity, local persistence when applicable, performance, and honest fictional framing.
- Automated engine, browser, balance, accessibility, release, and QA evidence requirements.
- Clear creative-director/Codex responsibilities, escalation, exceptions, and version pinning.
- Reusable GDD and Codex brief templates.

### Notes
- Existing games are not retroactively certified.
- Project-specific requirements and approved exceptions must be recorded in each project's GDD or acceptance record.
