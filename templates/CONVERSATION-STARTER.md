# Start or resume a project

Use any parts of this prompt that fit the task.

> I want to [explore an idea / build a prototype / ship a feature / fix a problem] for [project or repository]. The result I want is [what a user should see or do]. Start from [existing route, files, design or approved assets]. Preserve [important existing behavior].
>
> Work with me directly in this conversation. For exploration, help me compare the consequential choices. For implementation, inspect the current project, make routine engineering decisions, build and verify the result. Ask when a missing decision would materially change the experience, cost or exposure.
>
> Apply the project's pinned standards. My requested delivery destination, if any, is [specific repository, deployment URL and/or portal section]. Use the existing permissions and budget. Report the source revision, what you verified and anything still blocked.

For a clear fix, a single sentence describing the symptom and expected result is enough. Use the [design contract](GDD-TEMPLATE.md) for a formal baseline and the [handoff brief](CODEX-BRIEF.md) for an actual transfer.
