# Optional implementation handoff

Use this when transferring work to a different session, environment or implementer, or when the owner asks for a portable prompt. Fill only the fields needed to resume.

- **Goal and finish condition** — [owner's requested outcome and observable acceptance criteria]
- **Starting point** — [repository, branch, verified commit, entry point, relevant design or issue, standards pins]
- **Decisions and assets** — [accepted behavior, exclusions, exact source paths, licenses, approved fallbacks and delegated choices]
- **Work so far** — [implemented changes, reproducible checks, failures and outstanding work]
- **Authority** — [allowed repository writes, merge, precise deploy target, separate portal action, data and spending limits]
- **Next action** — [smallest concrete step that advances the outstanding work]

Recipient: inspect the current source, reconcile changes since the checkpoint, complete the authorized scope and verify the actual experience. Report source, test evidence and each requested deployment separately. Ask the owner only when a consequential choice remains unresolved.
